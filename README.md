## 反应速度测试 | Reaction Speed Test

### 📌 项目简介 | Introduction  
一个简洁优雅的网页应用，用于测量用户反应时间。无需依赖后端或框架，打开即用，支持多轮测试、排行榜记录、暗黑模式切换与动画打字反馈。

A clean and elegant web app that measures user reaction time. Fully client-side, no backend required. Supports multi-round testing, leaderboard tracking, dark mode toggle, and animated typing feedback.

### 🌟 主要特点 | Key Features

- ⏱️ **反应时间测试**  
  点击区域变绿时迅速反应，系统将精准记录你的反应时间（毫秒）。  
  ⬩ Test your reflexes by clicking as soon as the area turns green — response time is measured in milliseconds.

- 🏆 **排行榜系统**  
  自动保存成绩，展示历史最佳表现和平均反应时间，支持前三名高亮。  
  ⬩ Automatically saves scores and displays personal bests and averages. Top 3 are highlighted in the leaderboard.

- 🌓 **暗黑模式切换**  
  一键切换明亮与暗黑界面，兼容系统偏好设置。  
  ⬩ Toggle between light and dark themes with a single click. Respects system preferences.

- ✨ **动态反馈评语**  
  根据你的测试结果，生成打字机式趣味评语，增强交互体验。  
  ⬩ Fun and dynamic comments based on your results, rendered with a typewriter animation effect.

- 📱 **响应式设计**  
  适配手机与桌面端，保证跨设备流畅体验。  
  ⬩ Fully responsive design for seamless experience on mobile and desktop devices.

- ⚙️ **自定义测试轮数**  
  预设1/3/5次测试选项，支持自定义次数设置。  
  ⬩ Choose from preset rounds or enter a custom number of tests.
